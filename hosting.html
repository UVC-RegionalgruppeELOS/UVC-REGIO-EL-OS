Hosting & Technik

Diese Website der UVC Regionalgruppe Emsland–Osnabrück basiert auf einer modernen, zuverlässigen und datensparsamen technischen Infrastruktur. Hier findest du eine Übersicht über die eingesetzten Systeme.

1. Hosting über GitHub Pages

Die Website wird über GitHub Pages gehostet – einem schnellen, stabilen und weltweit verfügbaren Hosting‑Dienst für statische Webseiten. Änderungen an den HTML‑Dateien werden automatisch veröffentlicht.

2. Kontaktformular (Formspree)

Das Kontaktformular nutzt den Dienst Formspree, um Nachrichten sicher zu übermitteln. Dadurch ist kein eigener Mailserver notwendig.

3. Besucherzähler (Counter12)

Der Besucherzähler stammt von Counter12. Er verarbeitet IP‑Adressen anonymisiert und zeigt die Besucherzahlen ausschließlich im Footer der Startseite an.

4. Verlinkte Drittanbieter‑Dienste

Auf der Seite „Weiterführende Links“ werden eine Stellplatzkarte (Google Maps) sowie Musikvideos (YouTube) verlinkt. Es werden keine externen Inhalte direkt eingebettet; erst beim aktiven Öffnen eines Links können Daten an den jeweiligen Anbieter übertragen werden.

5. Technische Umsetzung

Die Website wurde vollständig in HTML, CSS und schlankem JavaScript erstellt. Es werden keine Cookies gesetzt und keine Tracking‑Dienste verwendet.
