Hosting & Technik

Diese Website der UVC Regionalgruppe Emsland–Osnabrück wird technisch über moderne, zuverlässige Dienste betrieben. Hier findest du eine Übersicht über die eingesetzten Systeme.

1. Hosting über GitHub Pages

Die gesamte Website wird über GitHub Pages gehostet. GitHub stellt eine sichere, schnelle und stabile Infrastruktur bereit, die ideal für Vereinswebseiten ist.

2. Kontaktformular (Formspree)

Für das Kontaktformular nutzen wir den Dienst Formspree. Dadurch können Nachrichten sicher übermittelt werden, ohne dass ein eigener Mailserver notwendig ist.

3. Besucherzähler (Counter12)

Der Besucherzähler stammt von Counter12. Er verarbeitet IP‑Adressen anonymisiert und zeigt die Besucherzahlen im Footer an.

4. Eingebettete Inhalte

Auf der Seite „Weiterführende Links“ wird eine Karte von Google Maps eingebettet. Dabei können Daten an Google übertragen werden.

5. Technische Umsetzung

Die Seite wurde vollständig in HTML und CSS erstellt. Es werden keine Cookies gesetzt und keine Tracking‑Dienste verwendet.
